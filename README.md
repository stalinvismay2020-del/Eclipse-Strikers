# Eclipse Strikers

Anime-inspired football game project for Android.

## Engine migration
- UnityProject/ — Unity 2022.3 LTS prototype under active migration.
- Original Godot files at the repository root are preserved.

The Unity prototype currently has a basic offline 4v4 match, generated pitch, placeholder players, ball physics, simple bots, five-minute timer, player switching, shoot/pass/tackle/sprint/special-burst actions, basic touch-area movement, character/team-color selection, tutorial hint, pause/rematch, simple local coins/reward and settings toggles.

**This is not yet the finished anime football game.** Final models, animation rigs, VFX/audio, robust mobile joystick, full football rules, cloud accounts, friend systems, online matchmaking, and tested Unity Android APK remain unfinished. See UnityProject/FEATURES.md for details.

The existing Android workflow builds the old Godot version, not the Unity project. No Unity APK is claimed until Unity Editor Android export and device testing succeed.
