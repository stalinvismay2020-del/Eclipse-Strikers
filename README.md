# Eclipse Strikers

Anime-inspired 3D football game for Android.

## Engine status
- `UnityProject/` — new Unity 2022.3 LTS migration prototype (early stage).
- Godot project files at the repository root — preserved while the Unity version is developed.

## Unity prototype
The Unity project currently generates a basic 4v4 pitch, goals, placeholder players, ball physics, simple bot movement, a five-minute timer, score HUD, and shoot/switch controls at runtime. It is **not yet a polished anime game**: proper character models, animation rigs, stadium art, abilities/VFX, sound, robust mobile controls, and multiplayer still need work.

Open the `UnityProject` folder with Unity 2022.3 LTS. An Android APK has not yet been built from the Unity project; building requires Unity Editor with Android Build Support and a configured Unity license.
