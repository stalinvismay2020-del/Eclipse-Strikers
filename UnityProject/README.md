Eclipse Strikers — Unity migration prototype

This is a separate Unity project folder so the existing Godot version remains preserved during migration.

Editor target: Unity 2022.3 LTS.

Current prototype: runtime-generated football pitch, goals, 4v4 placeholder players, ball physics, simple opponent movement, five-minute timer, score HUD, keyboard test controls, and on-screen shoot/switch buttons.

This is an early prototype, not the finished anime football game. It does not yet include finished character models, animation rigs, a proper touch joystick, ability effects, sound, or online matchmaking. All characters are simple placeholders until original/licensed assets are added.

To open: open the UnityProject folder in Unity 2022.3 LTS and open Assets/Scenes/Main.unity.

Android APK note: Unity Editor and Android Build Support are required. Cloud builds require a configured Unity license. The old Godot APK workflow does not build this Unity project. Do not treat the APK as available until a Unity build artifact has actually been produced and tested on a device.
